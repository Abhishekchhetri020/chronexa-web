Vite Reference

Commands, config patterns, and CLI flags for daily use.

Commands

npm create vite@latest my-app -- --template vanilla   # New project
npm install                                            # Install deps
npm run dev                                            # Start dev server (localhost:5173)
npm run build                                          # Production build → dist/
npm run preview                                        # Preview the production build locally

Key flags

vite --port 4000        # Custom port
vite --open             # Auto-open browser
vite build --watch      # Rebuild on change
vite build --minify false   # Skip minification (debugging)

vite.config.js for vanilla JS projects

import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [tailwindcss()],
  build: {
    rollupOptions: {
      input: { main: 'index.html' },
      output: { manualChunks: { solver: ['js/solver/csp_solver.js'] } }
    }
  }
})

HTMX / multi-page apps

import { resolve } from 'path'
export default defineConfig({
  build: {
    rollupOptions: {
      input: {
        main: resolve(__dirname, 'index.html'),
        about: resolve(__dirname, 'about.html'),
      }
    }
  }
})

Environment variables

import.meta.env.VITE_API_URL   # Must be prefixed VITE_
import.meta.env.MODE            # 'development' | 'production'
import.meta.env.DEV             # true in dev
import.meta.env.PROD            # true in production

Common plugins

@vitejs/plugin-vueVue SFC support
@vitejs/plugin-reactReact + HMR
@tailwindcss/viteTailwind v4 as plugin (no CDN)
vite-plugin-pwaService Worker + manifest
vite-plugin-static-copyCopy static assets to dist/

├── sw.js                        # via vite-plugin-pwa
└── manifest.webmanifest

Tips

  • Put all your source in src/ (convention, not required)
  • Vite treats index.html as the entry point — it auto-injects <script type="module">
  • Use relative paths in HTML; Vite resolves them
  • Existing IIFE scripts work without changes — just add them to index.html as normal <script> tags or import them in main.js
  • For Chronexa's 168 IIFE files, you can keep concatenating with build_bundle.sh and point Vite at the output — no need to rewrite everything at once
